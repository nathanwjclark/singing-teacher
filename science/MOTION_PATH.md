# Conditional temporal comparison of recorded audio hypotheses

`couple_motion_hypotheses(windows)` consumes the existing at-most-three motion PCM fit outputs. `app_motion.py` publishes its result as optional `temporalAnalysis`, while retaining every independent window/candidate unchanged. No synthesis, extraction or baseline update is added.

The implementation enumerates complete anatomical alternatives shared across **every usable window in the recording**, including separated segments. For each fixed anatomy, deterministic dynamic programming selects existing JA/gain candidates within each temporally linked segment. It minimizes:

`sum(existing weighted mean-square PCM discrepancies) + λ sum[(ΔJA / 1 degree)² + (Δlog2 gain / 1 octave)²]`.

λ values **0,0.1,1** are predeclared sensitivity settings, not fitted values. The penalty is a dimensionless engineering preference for smaller parameter changes. It is not a calibrated motor-control prior, physical motion model, likelihood or posterior. λ0 still imposes one shared anatomy and therefore differs from unconstrained independent winners. Each sensitivity result retains all anatomical alternatives, objective/data/unweighted-transition/weighted-transition components, chosen candidates and exact tied-best anatomy hashes. Stable deterministic ordering resolves ties without claiming superiority.

Acoustic frame spans use actual source excerpt start samples, within-excerpt frame offsets, sample rates and canonical window duration. A gap **greater than0.5seconds between measured acoustic frame spans** breaks control transitions. Missing/unscorable windows also break them. This maximum link interval is an explicit modeling assumption; it does not establish measurements in the gap. Typical long recordings with only start/middle/end excerpts have no temporal links: status is `no-temporal-links`, with shared-anatomy aggregation only. Camera tracking gaps are not mapped into audio because synchronization is unknown. Anatomy remains fixed even across broken control transitions.

Unavailable/nonfinite candidates are excluded and their window is retained with a reason if no comparable candidate remains. Combining costs requires identical canonical extractor/native provenance, feature units/scales and observed objective descriptor availability. Incompatible scales yield unavailable analysis, never per-window normalization or silent averaging. Reused physical frames and reversed/overlapping acoustic windows are excluded. If no single anatomical alternative covers every usable window, the analysis is unavailable rather than switching anatomy across time. Partial evidence is explicitly marked.

`temporalAnalysis` includes `settings`, `segments` (positions, measured spans and transition counts), `excludedWindows`, `independent`, and `sensitivity` (λ, alternatives, best, ties). Every path row contains original candidate identity, full anatomy/hash, conditional JA/gain and data cost. `additionalSynthesisCalls:0` and `modelUpdated:false` are explicit. F0 remains each frame's measured conditioning value and the source model remains the original fitter's fixed assumptions. A smooth path is a conditional explanatory hypothesis, not measured articulation, recovered trajectory, closure, muscle activity or validated anatomy.

Verification: `PYTHONPATH=science/src python -m pytest science/tests/test_motion_path.py science/tests/test_app_motion.py -q`. Targeted checks cover a regularizer-induced choice change, globally fixed anatomy across a missing middle/long gap, preservation of independent winners, nonfinite candidate exclusion, incompatible objective scales and actual encoded native audio passing through the unchanged synthesis budget.
