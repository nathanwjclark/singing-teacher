# Dynamic conditional reconstruction (MOT-02)

`singing_physics.dynamic.fit_dynamic(engine, document, *, budget_per_model=120, starts=3, seed=1, anatomy_bounds=None, articulation_bounds=None)` groups synchronized frames by attempt, cue and context, then uses the existing joint fitter for one shared anatomy and independent per-frame requested articulation. Visible lip measurements enter the same physical likelihood at their own timestamps. It does not rigidly average changing surfaces, interpolate missing movement, or estimate true anatomical movement limits.

This executable internal profile accepts **synthetic direct-transfer spectra**, not phone microphone audio. The inherited joint profile requires at least two different calibration poses across the input and supports at most 30 frames. A steady single-vowel motion observation can still be retained by the geometry module but cannot alone initialize this inverse fit. The current varying control is JA; the rest of the native articulation is inherited and fully recorded after native limiting.

## Input and capture integration

Use `schema_version: "0.1.0"`, `kind: "dynamic_synthetic_transfer_unknown_articulation"`, native `provenance`, `sample_rate_hz`, `spectrum_bins: 512`, optional positive `spectral_sigma_db`, and `attempts`. `max_gap_seconds` defaults to 0.1 and must be positive; it is a declared segmentation threshold, not a validated physiological cutoff.

Each attempt supplies unique `attempt_id`, `cue_id`, `cue_version`, `context_id`, a nonempty JSON `context`, explicit `split` (`calibration` or `held_out`), `cue_delivered_seconds`, and nonempty `frames`. Optional `actual_onset_seconds` remains a separate observed-timing declaration; missing onset stays null. It must lie within captured frames and is never manufactured from cue delivery. Cue delivery may occur before or during the capture, but cannot follow all its frames. Optional `mode` is `elicited`, `recalled` or `transfer`; `execution_status` is `successful`, `unsuccessful` or `unknown`. Geometry `outcome: "completed"` is not automatically interpreted as successful learning; `unsuccessful` is preserved.

Frames provide unique `id`, timestamp, timebase, nonnegative synchronization bound, `audio_evidence_id`, `pose`, `frequency_hz`, and `magnitude_db`. Audio is joined by frame ID to `observations.geometry.motion.analyze_motion(...)` output. That output already provides visibility, geometry status, calibrated `geometry_observation`, and the explicit `geometry_reason` when absent. The caller adds actual audio observations and cue-delivery metadata; this adapter does not generate missing spectra.

A visible `geometry_observation` must be the existing calibrated visible-lip record, refer to the exact frame ID, and match its split. Existing joint checks enforce its operator, correspondence, evidence uniqueness and conservative 20 ms alignment. When geometry is `missing` or `occluded`, an explicit reason is required, its payload is not read, and **audio is retained**. Measured landmark coordinates, head-pose evidence and uncertainty are preserved separately from inferred native state.

Frame times must strictly increase within one attempt/timebase. Repeated frame IDs, repeated physical audio `(audio_evidence_id, timebase_id, timestamp_seconds)`, inconsistent context reuse, and explicit frame attempt/cue/context references that contradict their parent are errors. Gaps are retained with the actual interval and a new segment index, without connecting surfaces across the gap. Attempt contexts sharing an ID must have identical finite JSON content. Cue identity never sets a native parameter.

Held-out frames retain metadata and source identity for exclusion checks; their spectra, geometry and pose values are never consumed by fitting. No held-out reconstruction is produced. Held-out frame depth evidence IDs, when declared, cannot be reused by calibration geometry; this check reads identity metadata rather than the held-out geometric payload. Malformed calibration audio is an error even when depth is absent: it is not silently dropped to improve fit. The joint fitter restores native anatomy on success and failure, and caller input is copied rather than edited.

## Output and control-model boundary

The result has `kind: "dynamic_conditional_reconstruction"`, a `shared_anatomy` labeled `hypothesis_not_direct_measurement`, complete nested `joint_fit`, attempt/frame records, and explicit excluded-geometry records. Every fitted frame retains requested articulation and all native requested/applied controls. `state.source_kind` is `inferred_articulation`, `reconstruction_only` is true, `measurement_sigma_deg` is null, and uncertainty is `uncalibrated_conditional_on_model_and_observations`.

Visible measurements and conditional native predictions have distinct fields. Missing geometry is null rather than a zero measurement. Its frame still has an acoustic-conditioned inferred state. The trajectory is a post-capture reconstruction, not a prospective forecast. There is no temporal penalty: sampling more frames does not add an undocumented smoothing force or per-frame velocity assumption, although additional acoustic observations still add likelihood terms. Gap segmentation is metadata; no dynamics are asserted through unobserved intervals.

`model_id` hashes the selected complete physical fit (including anatomy and per-frame states), calibration digest and native provenance. Frame `derived_model_id` references that snapshot. To feed a subsequent control model, a caller must explicitly choose an attempt-level summary and preserve inferred-source/uncalibrated-uncertainty labels, binding the control profile to this physical snapshot. Frames are not independent repetitions, and this adapter does not invent a precise JA uncertainty or equate immediate execution with learned recall/transfer.

## Verification and remaining evidence gates

Real-native tests use three timestamped frames with varying JA, /a/-/i/-/a/, actual native visible-lip distances, calibrated synthetic depth and the motion helper. They verify that changing a visible measurement changes the joint objective, full inferred states and measured landmarks remain distinct, gaps are explicit, occluded geometry retains audio, unsuccessful measured neutral execution is preserved, cue relabeling does not command a different state, held-out values are excluded, and invalid metadata/duplicates fail closed. Run `python -m pytest science/tests/test_dynamic.py -q -W error` with the science environment and repository modules available.

These tests establish execution and evidence flow; they do not demonstrate accurate human trajectory recovery, calibrated hidden-state uncertainty, real device synchronization, motor-learning improvement or physiological maxima. Real iPhone capture, the public microphone-feature contract, and independent learner/retention evaluation remain separate gates.
